# Codex Browser Adapter

Use only a browser-control tool available in the calling environment and its currently documented APIs. Follow initialization requirements, inspect current tabs/frames/controls, and refresh references after navigation or reloads. Transient IDs, expired URLs, coordinates, and session scripts are not durable instructions. If no suitable tool or access is available, report that boundary and continue available preparation; this adapter does not install tools or establish compatibility.

Keep task authorization separate from runtime permission. Identify actual immediate effects from the target model, including exposure after import/save. Feed concrete app/access and save/submit boundaries into the intervention plan. Filesystem grants do not establish browser/app access, but valid access does not require a new attendance window. The harness determines prompt conditions and grant lifetime.

Confirm that inputs commit to the form, finish all required save stages, reopen, and compare interpreted saved values and actual rendering with the model. After an uncertain write or disconnect, inspect current state before retrying. Distinguish availability, observed waiting, execution, and unknown outcomes rather than guessing a cause.

Keep credentials, student data, course identities, and local paths in appropriate task state rather than reusable instructions. This Codex-specific adapter has no implicit live-validation or other-agent support claim.
