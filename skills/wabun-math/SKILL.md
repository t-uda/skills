# Wabun Math

Load only the relevant skills:

- Terminology selection, translation, glossaries or terminology audits in any passage: [wabun-math-terminology](../wabun-math-terminology/SKILL.md).
- Explicitly structured definitions, lemmas, propositions, theorems, corollaries, proofs and remarks, including explicit Markdown equivalents: [wabun-math-theorem](../wabun-math-theorem/SKILL.md).
- Narrative prose, motivation, section introductions and explanations of results: [wabun-math-style](../wabun-math-style/SKILL.md).
- Personal writing conventions elected by the user or project: [math-writing-preferences](../math-writing-preferences/SKILL.md).

For mixed documents, route by passage and task. Reuse the same terminology evidence record. Companion skills are installed separately; resolve them from the available skill catalog if a sibling path is absent, and report a missing required companion rather than silently skipping it.
